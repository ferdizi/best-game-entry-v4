# FLOODWARDEN — Hold the Three Valleys

Route the flood. Feed the towns. Turn back the Delugewyrm.

A complete original browser game for make.fun best-game-01: route floodwater
from three mountain springs through canals to the towns of Reed Hollow,
Millstone Basin and Saltmarsh Delta. Seven floods, six hazards, a three-phase
boss, a six-build economy, pressure, combos and a dense HUD.

Play it: serve `game/` with any static server and open `game/index.html` in
desktop Chrome. No network requests, no external files.

- Mouse: place a build on a tile. Keys 1–6: choose a build. Right-click: refund.
- SPACE: release the flood. M: sound. R: restart after the end screen.
- WIN: survive all 7 floods, feed the towns, break the Delugewyrm (300 HP).
- LOSE: valley health hits 0, or a flood feeds fewer towns than its target.
